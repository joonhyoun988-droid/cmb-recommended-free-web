# CMB DORA Metrics Plan

Status: ready_not_live

## Metrics

- lead time: time from accepted change to deployed preview or production
- deployment frequency: number of preview/production deployments per week
- change failure rate: percentage of deployments causing rollback, failed save, broken login, or field-blocking defect
- recovery time: time from detection to restored working service
